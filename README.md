# FitBud

| **Commit Type** | **Description**                                                                                                       |
|-----------------|-----------------------------------------------------------------------------------------------------------------------|
| **feat**        | Introduction of a new feature or functionality in the codebase.                                                      |
| **fix**         | Resolves a bug in the code and ensures correct behavior.                                                             |
| **chore**       | Changes related to maintenance that don’t affect source or test files (e.g., updating dependencies).                 |
| **refactor**    | Improves code structure or readability without changing functionality or fixing bugs.                               |
| **docs**        | Updates or additions to documentation, such as README or other markdown files.                                      |
| **style**       | Changes related to code style or formatting, like fixing indentation, spacing, or missing semicolons.               |
| **test**        | Adds new tests, updates existing ones, or fixes issues in tests to improve coverage.                                |
| **perf**        | Improvements that enhance the performance or efficiency of the code.                                                 |
| **ci**          | Changes related to continuous integration (CI) configuration, workflows, or scripts.                                |
| **build**       | Changes affecting the build system, dependencies, or project tools.                                                  |
| **revert**      | Reverts a previous commit and rolls back the changes it introduced.                                                  |
| **pr**          | Creating a pull request.                                                                                             |
| **merge**       | Merging a pull request.                                                                                              |
